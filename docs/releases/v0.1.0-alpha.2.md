# EpochDeck 0.1.0-alpha.2

This prerelease improves run recovery, dashboard usability, and release
validation. It remains intended for single-user evaluation on disposable or
independently backed-up storage behind an authenticated HTTPS reverse proxy.

## Highlights

- Exclusive SDK spool ownership prevents overlapping writers from corrupting
  sequence and delivery state. Interrupted final journal appends recover with
  an explicit warning, and `Run.close()` supports stopping and resuming delivery.
- Real SDK/server contract checks cover metric, media and artifact delivery,
  abrupt server termination, restart, and physical backup/restore.
- Smoother vector branding and supersampled browser icons, generated from one
  SVG master with `just brand-assets`.
- More consistent sidebar, mobile run selection, artifact browsing, media
  timelines and histogram presentation; sharper canvas rendering in Chromium.
- Chart density controls, exact metric-key counts, and fixes for stale or failed
  requests occupying dashboard scheduler slots.
- Updated the development test runner to Vitest 4.1.11 to address
  [GHSA-82fw-gwwq-j7x9](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9).
- Smaller Rust source modules, a standalone catalog SQL definition, and a
  separate SDK delivery worker module.
- Native release archives for Linux x86_64/ARM64, Apple Silicon macOS, and
  Windows x86_64, plus a matching Python wheel and source distribution.

## Deliberate exclusions

Sweeps, agents, persisted reports, and structured execution traces have been
removed and are **Not planned**. Gradio and Hugging Face platform integrations
are also **Not planned**. See the [compatibility matrix](../compatibility.md).

## Upgrade and limitations

This release changes the disposable pre-alpha catalog. Stop and back up the
previous binary's complete root set, then start alpha 2 with empty storage
roots. Keep the prior binary and its roots together for rollback; there is no
stored-data migration promise. Install the matching `epochdeck-0.1.0a2` wheel.

Native authentication, multi-user authorization, stable data upgrades, and
sustained concurrent-load acceptance gates remain open. Read the
[readiness assessment](../readiness.md) and [operations guide](../operations.md)
before deploying.
