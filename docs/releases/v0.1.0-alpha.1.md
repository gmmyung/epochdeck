# EpochDeck 0.1.0-alpha.1

EpochDeck's first public prerelease is intended for single-user evaluation on
disposable storage.

## Highlights

- Durable, nonblocking Python logging.
- Lossless Arrow/Parquet metrics with bounded chart queries.
- Native media and versioned artifacts.
- Multi-run uPlot charts with configurable axes and smoothing.
- Independently configurable metadata, metric, and blob roots.
- Physical backup and portable project export.

## Limitations

- No native authentication or multi-user authorization.
- No stored-data migration promise between pre-alpha builds.
- Partial W&B compatibility and import coverage.
- No PyPI, crates.io, or npm publication.

Use the current guides for [installation](../deployment.md),
[security](../../SECURITY.md), and [compatibility](../compatibility.md).
